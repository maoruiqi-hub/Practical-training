# 可展示版本后端智能能力前端接通实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出一个可展示版本，把后端已有的错题、楼层状态、掌握度、知识图谱、能力图谱、AI 讲解和 AI 问答能力接到学生端爬塔流程与画像页面里。

**Architecture:** 后端仍作为事实源，前端只读后端状态并发起已有事件/API。塔图后端改为以知识点为楼层主键，聚合 `knowledge_point_floor_status` 与 `knowledge_mastery`；学生端在塔图、楼层战斗、休息点、宝箱和画像页展示智能能力。AI 能力统一通过已有 `CourseAiService -> AgenticClient`，前端新增一个可复用 AI 导师面板。

**Tech Stack:** Spring Boot + MyBatis Plus + Vue 3 `<script setup>` + Element Plus + ECharts + Axios。

## 2. 展示路径

演示按下面路径串起来，确保每个后端模块都有可见价值：

1. 学生登录进入塔图。
2. 塔图节点颜色来自 `knowledge_point_floor_status`，百分比来自 `knowledge_mastery`。
3. 点击薄弱节点进入楼层，右侧展示当前知识点的知识图谱上下文。
4. 战斗中点击“AI 导师”，可对当前题目/知识点提问；若有 PPT 资源，可触发 AI 讲解。
5. 休息点显示薄弱错题线索，并可打开 AI 导师复习。
6. 商店展示真实 `wrongList` 错题卡。
7. 宝箱展示课程资源，PPT 资源可以进入 AI 讲解。
8. 学生画像页展示能力图谱，把能力点、知识点掌握度、塔图状态连起来。
9. 教师端展示 AI 生成能力图谱草稿，一键采纳到已有能力点/知识点绑定接口。

## 3. 目标数据契约

### 3.1 `GET /api/students/{studentId}/tower-map`

后端返回的每个 floor 建议统一成下面结构：

```json
{
  "kpId": "kp-001",
  "knowledgePointId": "kp-001",
  "kpName": "列表与元组",
  "description": "掌握 Python 序列基础操作",
  "level": 3,
  "floorStatus": "weak",
  "masteryRate": 45,
  "masterySource": "knowledge_mastery",
  "isAccessible": true,
  "abilityPointId": "ap-002",
  "abilityPointName": "数据结构基础",
  "relatedAbilityPointIds": ["ap-002"],
  "statusReason": "floor_status:weak; mastery:45"
}
```

规则：

- `kpId` 必须是知识点 id，供 `/floor/:kpId`、题目查询、资源查询、AI 问答复用。
- `masteryRate` 优先取 `KnowledgeMastery.masteryScore`。
- 无掌握度时，用知识点映射到的能力点 `CompetencyScore.score` 回退。
- `floorStatus` 优先取 `KnowledgePointFloorStatus.status`。
- 状态表没有记录时，用 `masteryRate` 判定：`>=85 cleared`，`1..59 weak`，否则按顺序开放。
- `abilityPointId/abilityPointName` 仅作为展示装饰，不再作为楼层主键。

### 3.2 AI 讲解与问答 API

在 `frontend/src/api/index.js` 增加：

```js
export const explainKnowledgePoint = (knowledgePointId, data) =>
  api.post(`/api/knowledge-points/${knowledgePointId}/explain`, data)

export const askKnowledgePoint = (knowledgePointId, data) =>
  api.post(`/api/knowledge-points/${knowledgePointId}/qa`, data)

export const getKnowledgeMastery = (studentNo, courseCode) =>
  api.get(`/api/knowledge-mastery/student/${studentNo}`, { params: { courseCode } })
```

AI 请求体：

```json
{
  "resourceId": "resource-ppt-001",
  "pageNumber": 3,
  "question": "请用例子解释列表切片",
  "previousMessages": ["学生：...", "AI：..."]
}
```

AI 响应体来自 `AgenticResponse`：

```json
{
  "success": true,
  "data": {
    "answer": "..."
  },
  "message": "..."
}
```

前端渲染时按 `data.answer || data.content || data.text || message` 取文案。

8. 逐个知识点生成 floor。

状态判定函数：

```java
private String resolveFloorStatus(String saved, int mastery, boolean previousCleared, int index) {
    if ("cleared".equals(saved) || mastery >= 85) return "cleared";
    if (!previousCleared && index > 0) return "locked";
    if ("weak".equals(saved) || (mastery > 0 && mastery < 60)) return "weak";
    return "available";
}
```

注意：`previousCleared` 只控制顺序锁定，不覆盖后端已明确写入的 `cleared/weak`。
