# AI智慧课程（选定python编程与数据分析这一门课作为对象）产品需求
## 项目概述
随着人工智能技术的迅速发展，AI辅助教育正逐渐成为教育变革的重要趋势。当前传统的教学方式和评估体系，难以满足不同学生的个性化学习需求，内容难以精准适配学习者的知识结构和能力水平，需要创新性解决方案。本系统是一套深度融合人工智能技术的教育管理及学习辅助平台，以“智能化生产、结构化管理、个性化学习”为核心目标，构建覆盖课程全生命周期、教学全场景的数字化解决方案，实现教育资源高效管理与教学流程智能优化。

## 目标用户
- 高校教师
- 大学生

## 基础功能
1. 学生信息管理：支持学生信息的录入、修改、查询与批量导入导出。
2. 课程基本信息管理：管理课程基础信息，包括课程名称、课程编号、授课教师、学分、学时等数据。
3. 课程学习任务管理：每门课程可关联多个学习任务，如章节资料阅读、视频观看、PPT浏览、测试答题、实践项目等，支持教师自定义任务类型、任务说明、截止时间、提交方式。学生根据教师发布的任务，提交任务成果。
4. 学生用户学习并收集学生用户的学习数据：如试题完成情况与得分，任务完成时间与准确率。
5. 成绩多样化分析展示：成绩根据任务完成度动态更新，并能可视化（如柱状图、曲线图）呈现成绩变化趋势，教师端可导出成绩报表，学生端可接收个性化学习反馈。

## 拓展功能
1. 任务类型支持多样化，如：章节作业、试卷答题、课程视频观看、阅读教材/PPT、报告类文档上传等。
2. 知识图谱的构建和可视化：知识图谱中每个节点代表一个知识点，放在节点上会展示知识点的粗略信息，点击节点可以进入该知识点的详细学习页面。知识图谱功能可自行进行拓展创新。
3. 资源的上传和下载：教师用户可上传PPT、教材PDF、参考资料、项目指导书、视频等多种资源。
4. 视频类资源学习进度的数据记录：如播放时长、跳过片段、重复观看某段落等数据均被记录。可生成视频学习热力图与完成率统计。
5. 测验题库设计，且可根据需求实现组卷功能：支持多题型题库管理（如选择、填空、简答、编程等），题目可关联知识图谱的知识点并可设置难度等级。教师可选择随机组卷、按知识点组卷、按难度平衡等方式生成测试试卷。

## 创新功能（运用大语言模型）：
1. 智能化的提取课程知识点用于知识图谱构建：实现一键生成课程知识图谱，自动组织节点层级与逻辑关系。
2. 能够根据成绩评估来进行学习内容的推荐，如根据学生在各类任务中的表现推荐知识点学习、复习材料学习、拓展材料学习。
3. 根据课程能力点构建对应课程的能力图谱并根据学习行为更新能力评分。
4. 实现学生报告的智能批改：对于学生提交的PDF/Word形式的课程报告、论文或简答题回答能进行智能化评分。课件ppt知识点智能讲解，就像微助教那个，可以对话的那种。
5.学习风险预警与干预建议：系统根据学生的任务拖延、连续低分、长期未登录、学习进度明显落后等情况，自动识别学习风险，并在教师端生成预警信息，提示教师及时关注相关学生并采取针对性辅导。
6.班级共性问题聚类：系统自动汇总学生的错题、提问、任务反馈和学习疑问，将相似问题进行归类，形成班级高频问题列表，帮助教师快速判断哪些内容需要重新讲解、补充案例或调整教学安排 
7.学生激励

## 页面流程
1. 注册/登录后进入主页，不同的用户（如教师、学生），可以有不同的主页风格或主页内容，主页包含导航栏和系统的基本介绍；
2. 导航栏包括模块，如教师用户的导航栏有【班级管理】【学生管理】【任务】【成绩管理】等，学生用户的导航栏有【课程管理】【作业】【成绩查看】可以点击模块进行跳转；
3. 如教师用户点击导航的【任务】模块，通过任务界面发布、修改或查看任务相关的资源；
4. 如教师导航点击【成绩管理】来查看学生的任务完成情况和评估得分；
以上4条页面流程仅为参考样例，可以以教师端为主要内容，学生端作为辅助测试内容为辅，鼓励同学们自主设计页面流程。

3. 界面简洁，核心功能 ≤3 步可完成

### 可扩展性:
