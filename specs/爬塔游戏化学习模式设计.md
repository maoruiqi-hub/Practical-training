# 爬塔游戏化学习模式设计

> 将 Roguelike 爬塔游戏（以《杀戮尖塔 Slay the Spire》为核心参考）的完整概念体系，映射到 **Python编程与数据分析基础** 课程平台，构建"渐进式挑战 → 能力成长 → 自适应路线"的游戏化学习体验。

---

## 一、爬塔原概念 → Python课程 映射总表

### 1.1 塔与地图

| 爬塔原概念 | Python课程对应 | 说明 |
|-----------|---------------|------|
| 塔 | **Python编程与数据分析基础**（整门课程） | 一座塔 = 一门课，通关 = 完成课程 |
| 区域 (Act) | **三大阶段**：基础语法 → 数据处理 → 分析实战 | 每区域结尾有 Boss |
| 楼层 | **单个知识点**（如"列表与字典"） | 每层 = 一个可挑战的知识节点 |
| 节点地图 | **知识图谱** | 分支路线 = 知识点前置依赖关系 |
| Boss 层 | **阶段综合测验 / 大作业** | 需综合该区域所有知识点 |
| 精英怪层 | **拔高题 / 挑战题** | 难度高于普通题，奖励更多 |
| 普通怪层 | **标准练习题** | 选择题、填空题、基础编程题 |
| 休息点 | **复习节点** | 回顾已学知识，巩固薄弱点 |
| 商店 | **资源中心** | 用积分兑换学习资料 |
| 宝箱 | **隐藏奖励** | 完成特定条件触发额外学习资源 |
| 随机事件 | **拓展练习 / 随机测验** | 不可预测的学习机会，有风险有收益 |
| 隐藏层 | **彩蛋知识** | 满足隐藏条件解锁的进阶内容 |

### 1.2 角色与属性

| 爬塔原概念 | Python课程对应 | 计算逻辑 |
|-----------|---------------|---------|
| 英雄/角色 | **学生画像** | 每个学生有自己的属性面板 |
| HP（生命/信心值） | **连续失败容忍度** | 初始100，每错一题-10，归零触发强制补给 |
| ATK（攻击/解题力） | **当前知识点的正确率** | 最近10题加权正确率，影响"战斗"效率 |
| DEF（防御/基础度） | **前置知识掌握度** | 前置节点平均掌握度，越高则新题难度感知越低 |
| 能量/法力 | **每日学习精力** | 限制每天可挑战的楼层数，用尽需休息 |
| 金币 | **积分/学分** | 答题正确+20，Boss+100，用于商店兑换 |
| 经验值 (EXP) | **累计做题数** | 每题+10，Boss+50，决定等级 |
| 等级 | **能力评级** | 入门 → 初级 → 中级 → 熟练 → 精通 |
| 得分 | **总评成绩** | 通关后的综合评分 |

### 1.3 战斗系统

| 爬塔原概念 | Python课程对应 | 说明 |
|-----------|---------------|------|
| 回合制战斗 | **一道题的答题过程** | 学生提交 = 出招，系统判定 = 结算 |
| 敌人 | **一道练习题目** | 有类型（选择/填空/编程）、难度、考察知识点 |
| 敌人意图预告 | **题目前置信息面板** | 展示考察知识点、预计耗时、前置要求、奖励预览 |
| 普通攻击 | **直接提交答案** | 最基础的答题行为 |
| 技能/卡牌 | **解题策略/技巧** | 如"查看提示""代码补全""运行调试"（有限次） |
| 牌组 | **已掌握知识集合** | 牌组质量 = 知识结构的完善程度 |
| 弃牌堆 | **错题本** | 做错的题进入错题本，阶段结束重新挑战 |
| 防御 | **查看参考资料** | 不推进但也不扣HP |
| 逃跑 | **暂时跳过** | 标记为"薄弱"，稍后再战 |

### 1.4 状态与效果

| 爬塔原概念 | Python课程对应 | 说明 |
|-----------|---------------|------|
| Buff（增益） | **学习状态加成** | 如"全神贯注"：答题效率+20% |
| Debuff（减益） | **学习障碍** | 如"概念混淆"：关联题错误率上升 |
| 中毒 | **知识误区** | 持续多题受影响，需"解药"（针对性讲解） |
| 虚弱 | **基础薄弱** | 前置知识不牢导致当前层ATK下降 |
| 易伤 | **思维定势** | 同类题型连续错，伤害加深 |

### 1.5 成长与构筑

| 爬塔原概念 | Python课程对应 | 说明 |
|-----------|---------------|------|
| 遗物/神器 | **成就徽章** | 被动永久效果，改变学习体验 |
| 药水/补给 | **学习资源包** | 一次性使用：复习讲义、代码示例、视频片段 |
| 卡牌升级 | **知识深挖** | 在复习节点深化某个已学知识点 |
| 卡牌移除 | **优化学习路径** | 系统识别无效学习行为，建议跳过冗余步骤 |
| 祝福/诅咒 | **开局选择** | 课程开始时选择一种学习风格增益 |
| 进阶难度 | **能力分层** | 基础 → 拓展 → 创新，逐级加深 |

### 1.6 元系统

| 爬塔原概念 | Python课程对应 | 说明 |
|-----------|---------------|------|
| 解锁新角色 | **解锁后续课程** | 通关后可解锁更高级课程 |
| 日常挑战 | **每日一题** | 全班同条件竞技，排行榜展示 |
| 成就系统 | **能力认证** | 能力图谱上的认证标记 |
| 排行榜 | **班级/全站排名** | 按通关进度、积分排序 |
| 首通荣誉 | **率先通关记录** | 最先通关某层的同学留名 |

## 十二、技术实现要点

### 12.1 知识图谱 = 塔地图

- 每个节点存储：知识点名称、层级、前置依赖列表、题型关联、难度系数
- 前端渲染：力导向图/层级树，四色标记（灰✅/橙🔥/亮🔓/暗🔒）
- LLM输入：课程大纲/教材 → 输出：节点列表+依赖关系JSON

### 12.2 自适应路线算法

```
学生答题数据 → 掌握度计算 → 节点状态更新 → 地图重新渲染
                                  │
                    ┌─────────────┼─────────────┐
                    │             │             │
                  已掌握         薄弱         未解锁
               (正确率≥85%)  (40%~85%)    (前置未通过)
                    │             │             │
                    ▼             ▼             ▼
                 灰色跳过      橙色可选      锁定不可选
```

### 12.3 LLM 应用场景

| 场景 | 输入 | 输出 |
|------|------|------|
| 知识图谱生成 | 课程大纲/教材内容 | 节点列表+层级+依赖关系JSON |
| 入学诊断 | 学生基础信息 | 自适应题目序列+起始楼层推荐 |
| 智能补给 | 学生错误日志+当前知识点 | 精准学习资源推荐+个性化讲解 |
| 战斗结算 | 学生提交的代码/文本 | 评分+错误分析+改进建议 |
| AI导师对话 | 学生提问+当前知识上下文 | 对话式解答（类微助教） |
| 问题聚类 | 全班错题+提问+反馈 | 高频问题归类+教学建议 |
| 风险预警 | 学生行为数据 | 风险等级+干预建议 |
