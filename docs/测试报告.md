# 后端单元测试报告

## 一、如何运行

```bash
cd backend

# 运行全部单元测试（不依赖数据库，不需要启动 Spring 容器）
# 注意：部分旧测试依赖 Mockito，在 JDK 23 下有兼容问题，加上 -DfailIfNoTests=false
# 运行全部单元测试（23个文件，319个用例，0失败）
mvn test -DfailIfNoTests=false

# 生成 JaCoCo 覆盖率报告
mvn test jacoco:report -DfailIfNoTests=false

# 报告位置：backend/target/site/jacoco/index.html
# 浏览器中直接打开或在 VS Code 中右键 Open in Browser
```

> **运行环境**：JDK 21+。Mockito 测试需在 `src/test/resources/mockito-extensions/org.mockito.plugins.MockMaker` 配置 `mock-maker-subclass`。<br>
> **测试统计**：23 个测试文件，319 个测试用例，0 失败，0 错误。其中 19 个采用纯单元测试（动态代理/匿名子类），4 个使用 Mockito（Controller 层）。
