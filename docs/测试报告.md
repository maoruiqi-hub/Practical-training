# 后端单元测试报告

## 一、如何运行

```bash
cd backend

# 加载数据库环境变量（必须，否则 Spring 配置占位符解析失败）
set -a && source .env && set +a

# 运行全部单元测试（不依赖数据库，不需要启动 Spring 容器）
mvn test -Dtest="TeacherServiceTest,StudentServiceTest,LessonServiceTest,QuestionServiceTest,Module2ServiceTest,CourseServiceTest,ExamServiceTest,StatsServiceTest,LearningProgressServiceTest,RiskAlertServiceTest,ClassInfoServiceTest,AbilityPointServiceTest"

# 生成 JaCoCo 覆盖率报告
mvn test jacoco:report -Dtest="..."

# 报告位置：backend/target/site/jacoco/index.html
# 浏览器中直接打开或在 VS Code 中右键 Open in Browser
```

> **注意**：部分旧测试（`ApplicationTest`、`ApiContractMappingTest`、`CourseControllerTest` 等）依赖数据库连接和 Spring 上下文，在没有远程数据库时会失败，属于项目已有问题。新增的 12 个测试文件均采用纯单元测试方式，不依赖数据库，100% 通过。

### 测试方式说明

- **纯单元测试**：使用动态代理模拟 Mapper 层，不启动 Spring 容器，不连接数据库
- 测试覆盖**正常情况、异常情况、边界条件**三类场景
- Controller 层、AI Agentic 服务、文件存储等强依赖外部资源的组件未纳入单元测试，适合用 Spring 集成测试（`@SpringBootTest + MockMvc`）覆盖
