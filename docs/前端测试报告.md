## 五、测试方式说明

- **API 测试**：使用 `vi.mock('axios')` 全局 mock，导入真实模块，验证每个导出函数是否正确构造 HTTP 请求（方法、URL、参数、请求体）
- **路由测试**：提取 `beforeEach` 守卫逻辑和 `studentRoomRedirects` 映射为纯函数，覆盖所有7个重定向规则和边界情况
- **资源清单测试**：使用 `vi.mock` 替代 webpack `require()`，验证数据完整性、路径格式和命名规范
