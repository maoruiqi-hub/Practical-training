# 模块 1：课程内容与知识组织接口说明

状态：后端核心能力已实现；真实 AI、任务、题库和学习行为数据待联调。

## 数据归属

| 数据 | 归属 | 其他模块使用方式 |
|---|---|---|
| Course、CourseResource | 模块 1 | 只读查询；课程资源浏览会发布事件 |
| KnowledgePoint、KnowledgeRelation | 模块 1 | 必须使用 `courseCode + knowledgePointId` 引用，不要保存知识点名称 |
| AbilityPoint、AbilityKnowledgePoint | 模块 1 | 模块 4 只读能力点与映射 |
| KnowledgeMastery | 模块 1 聚合 | 模块 2/3 通过服务层写入学习证据，模块 4/5 读取结果 |

## 对外查询接口

| 接口 | 用途 | 权限 |
|---|---|---|
| `GET /knowledge-point?courseCode=` | 查询课程知识点 | 已登录用户 |
| `GET /knowledge-point/course/{courseCode}/graph` | 查询图谱节点和边 | 已登录用户 |
| `GET /knowledge-point/{id}/prerequisites` | 查询完整前置知识链 | 已登录用户 |
| `GET /ability-map?courseCode=` | 查询能力点与知识点映射 | 已登录用户 |
| `GET /knowledge-mastery/student/{studentNo}?courseCode=` | 查询个人掌握度 | 本人或课程教师 |
| `GET /course/{courseCode}/weak-points` | 查询班级薄弱知识点 | 课程教师/管理员 |

## 写入与事件约定

1. 模块 2（任务）和模块 3（题库）必须建立各自实体到 `knowledge_point_id` 的关联表；不要使用 `question.knowledge_point` 这类名称文本作为主关联。
2. 学习任务、测验、报告等完成后，应在同一 Spring 应用内调用 `KnowledgeMasteryService.upsert`，传入 `studentNo`、`courseCode`、`knowledgePointId`、`masteryScore`、`sourceType` 和 `sourceId`。HTTP `POST /knowledge-mastery` 仅供课程教师人工校正，学生不能调用。
3. 模块 1 在学生资源浏览时发布 `ResourceViewEvent`。模块 2 可监听该事件并持久化学习行为，随后据此计算掌握度。
4. 删除知识点会自动删除其图谱关系、能力映射和掌握度记录；课程资源会保留，但其知识点分类会被清空。

## Agentic 服务接入

默认 `agentic.mode=mock`，仅用于本地演示。接入真实服务时设置：

```text
AGENTIC_BASE_URL=http://your-agentic-service
```

并设置 `AGENTIC_MODE=http`。模块 1 会调用以下能力路径：

| 路径 | 请求关键信息 | 预期响应 `data` |
|---|---|---|
| `POST /extract` | `courseCode`、`resourceId`、资源元数据 | `knowledgePoints: [{name, description?, chapter?, importance?}]` |
| `POST /lecture` | 知识点、PPT 资源、页码、上下文 | `explanation`、`learningFocus`、`commonMistakes`、`example` |
| `POST /qa` | 知识点、资源、问题、历史对话 | `answer`、`citations` |
| `POST /ability-map` | 课程和知识点集合 | 课程能力点建议 |

Agentic 服务应根据 `resourceId` 取得受控课程资料；不要把私有文件路径或学生隐私数据暴露给浏览器。

## 本地配置

数据库密码不再写入仓库。参照 [`backend/.env.example`](../../backend/.env.example) 在 IDE、Docker 或部署环境配置 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`。PPT/Word 在线预览需要安装 LibreOffice 并设置 `COURSE_RESOURCE_OFFICE_PREVIEW_ENABLED=true`。
